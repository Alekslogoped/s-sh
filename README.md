# Снежные друзья

Игра для GitHub Pages: 12 снеговиков, поиск по головному убору, цвету шарфа и предмету в руках. Нажмите «Бросить кубики», затем выберите снеговика с тремя совпадающими признаками. Цель — собрать все карточки.

Кубики выбирают только оставшиеся карточки. Все сочетания уникальны. После двух ошибок подсвечиваются карточки с нужным головным убором. Найденные карточки переходят в коллекцию; поле сохраняет размеры и расположение ячеек. Поддерживаются сенсорное управление, клавиатура, выключение звука, повторная игра и уменьшение анимации через настройки устройства.

## Запуск

Откройте `index.html` в браузере или используйте GitHub Pages: ветка `main`, папка `/ (root)`. Сборка, зависимости и сервер не нужны. Иллюстрации находятся в `assets/` и загружаются без внешних сервисов.

Предыдущая игра «Пикник Сони и Миши» сохранена без изменений в `picnic.html`.

## Файлы

- `index.html` — разметка игры.
- `style.css` — адаптивное поле, зимняя сцена и анимации.
- `game.js` — сочетания признаков и логика.
- `assets/snowman-01.webp` … `assets/snowman-12.webp` — отдельные иллюстрации. Последняя карточка использует исправленный рисунок с двумя руками.
